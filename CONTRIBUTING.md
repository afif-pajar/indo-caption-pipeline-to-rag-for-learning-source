# Contributing

Contributions are welcome through pull requests.

1. Do not commit third-party media, generated transcripts, model weights, credentials, or personal data.
2. Create a focused branch and keep changes narrowly scoped.
3. Add or update tests for behavioral changes.
4. Run `uv run ruff check .`, `uv run pytest`, `uv run bandit -q -r src`, and `uv run pip-audit`.
5. Explain security, privacy, copyright, and compatibility implications in the pull request.

Report vulnerabilities privately as described in `SECURITY.md`.
